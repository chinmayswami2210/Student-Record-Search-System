
# Student Record Search System

## Description
A C++ based Student Record Search System that uses a Binary Search Tree (BST) to store, search, and manage student records.

## Features
- Insert New Student Record
- Search Student Record by Enrolment ID
- Delete Student Record
- Display Records in Sorted Order
- Inorder Traversal
- Preorder Traversal
- Postorder Traversal
- Compare Balanced and Skewed BST Efficiency
- Run Mandatory Test Cases

## Data Structure
Binary Search Tree (BST)

Each student record contains:
- Enrolment ID
- Student Name
- Department
